# Folder Organizer (Органайзер папок)

Невеликий графічний інструмент для сортування файлів у вибраній папці за типами файлів.

**Функції:**
- Автоматичне переміщення файлів у підпапки за розширенням (Зображення, Документи, Відео_та_Музика, Архіви)
- Створення підпапок за потреби
- Обробка конфліктів імен файлів (додає суфікс _1, _2 і т.д.)
- Файли з незвичними або відсутніми розширеннями потрапляють у папку "Інше"

**Вимоги:**
- Python 3.7+
- Модулі: `tkinter` (зазвичай вбудований), `shutil`, `os`

**Встановлення та запуск:**
1. Скачайте або клонуте репозиторій.
2. Запустіть скрипт:

```bash
python folder_organizer.py
```

Відкриється GUI: натисніть «Обрати папку», вкажіть папку для сортування, потім натисніть «Розсортувати».

**Налаштування категорій:**
Категорії й відповідні розширення задаються у файлі `folder_organizer.py` в словнику `EXTENSIONS`.
Приклад:

```python
EXTENSIONS = {
	'Зображення': ['.jpg', '.png', '.gif', '.jpeg'],
	'Документи': ['.pdf', '.docx', '.txt', '.xlsx'],
	'Відео_та_Музика': ['.mp4', '.mov', '.mp3', '.wav'],
	'Архіви': ['.zip', '.rar']
}
```

Додайте або змініть категорії відповідно до ваших потреб.

**Як обробляються конфлікти імен:**
Якщо файл з таким же іменем вже існує в цільовій папці, скрипт додає суфікс `_1`, `_2` і т.д., щоб уникнути перезапису.

**Приклад:**
- В папці з файлами є `photo.jpg`, `report.pdf`, `song.mp3`. Після запуску вони будуть переміщені в підпапки `Зображення`, `Документи`, `Відео_та_Музика` відповідно.
